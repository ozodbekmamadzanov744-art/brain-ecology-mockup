# Brain Ecology — UX-макет

Кликабельный макет сайта и обучающей платформы для согласования с заказчиком.
Чистый HTML + CSS + JS, без сборки и без сервера.

## Как открыть

Двойной клик по `index.html` — откроется в браузере.

Если какой-то браузер ограничивает работу с локальными файлами, можно поднять
встроенный в JDK 18+ сервер из папки макета:

```
jwebserver -p 8090
```

и открыть http://localhost:8090

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная страница сайта |
| `course.html?id=1` / `?id=2` | Страница курса (данные курсов — в `js/main.js`, объект `COURSES`) |
| `login.html` | Вход / регистрация (`login.html#register` — сразу вкладка регистрации) |
| `cabinet.html` | Главная личного кабинета ученика |
| `module.html` | Прохождение модуля (урок) |

## Что работает в макете

- мобильное меню, аккордеон модулей курса, вкладки вход/регистрация;
- заявка для компаний и вопрос куратору — модальные окна (данные никуда не отправляются);
- задачи на сегодня отмечаются, самооценка состояния сохраняется через ползунки;
- «плеер» видео, «Завершить урок» обновляет прогресс.

Состояние хранится в `localStorage` браузера — чтобы сбросить демо, очистите данные сайта.

## Заглушки

Всё в квадратных скобках (`[ЦЕНА]`, `[Имя Фамилия]`, `[N] месяцев`, фото, обложки)
— данные, которые должен прислать заказчик.

## Перенос в Spring + FreeMarker

`css/` и `js/` → `src/main/resources/static/`, страницы → `templates/*.ftlh`;
повторяющиеся шапку, подвал и меню кабинета вынести в макросы layout.
